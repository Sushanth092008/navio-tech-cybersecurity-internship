# Major Project Test Checklist

Run by opening `index.html` in a current browser.

- [ ] Page loads without external network requests.
- [ ] Safety notice is visible before interaction.
- [ ] Mock email uses the reserved `.invalid` domain.
- [ ] No password, OTP, or credential input exists.
- [ ] “Inspect warning signs” reveals the checklist and increments local counters.
- [ ] “I would report this” increments only the local report-choice counter.
- [ ] “Reset local counters” clears counts and hides the checklist.
- [ ] Keyboard focus is visible on buttons.
- [ ] Layout remains usable on a narrow mobile viewport.
- [ ] Browser refresh resets all in-memory counts.

Record browser, operating system, date, and actual outcomes when executing tests. Do not mark tests complete until they have been run.
