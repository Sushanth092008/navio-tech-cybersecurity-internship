# Major Project: Phishing Awareness Simulation Using Social Engineering Techniques

A safe, local-only awareness demonstration. It shows a mock phishing-style email and an educational landing page, records only anonymous button interactions in the current browser session, and never asks for or stores passwords.

## Run
Open `index.html` in a modern browser. No server, third-party package, or network access is required.

## Ethical safeguards
- Do not send the sample email to people without prior approval and informed consent.
- Do not impersonate a real organization or collect credentials.
- This demo does not send email, track real recipients, fingerprint devices, or transmit analytics.
- Resetting the page clears the in-memory counters.

## Deliverables
- Harmless mock email and awareness landing page.
- Local interaction counters (viewed demo, clicked training link, reported sample).
- Instructor/participant briefing template.
- Report and test checklist.
