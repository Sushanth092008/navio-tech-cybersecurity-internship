# NavioTech Cybersecurity Internship Projects

Academic portfolio containing all three projects allocated in the NavioTech Solution internship brief.

## Projects

1. **Minor Project 1 — Cybersecurity Risk Assessment Framework for Small Businesses** — initial Python CLI implementation, illustrative risk register, automated test suite, and report.
2. **Minor Project 2 — Zero Trust Architecture for Enterprise Security** — initial Python policy simulator for MFA, RBAC, device trust, secure-channel requirements, tests, and report.
3. **Major Project — Phishing Awareness Simulation Using Social Engineering Techniques** — local-only HTML/CSS/JavaScript awareness demonstration, ethical-study protocol, test checklist, and report.

## Academic integrity and safety

Sample risk scores and Zero Trust access decisions are illustrative. No real organization has been assessed and no enterprise network has been tested. The phishing project is a local training demonstration: it does not send emails, collect credentials, transmit analytics, or track individual recipients. Participant research requires prior instructor/institutional approval and informed consent.
